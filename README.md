# MiningFOMC V2 (`fomc-app`)

Full-stack analytical web application for exploring, auditing, and comparing historical Federal Open Market Committee (FOMC) documents (1976–2020), integrated into the `mining-fomc` monorepo.

## Standalone Database (`./fomc-data`) & Database Versioning (`VERSION.json`)

`fomc-app` is designed to operate as a **100% self-contained repository** with its compact, versioned Parquet database stored in `./fomc-data` (~167 MB total, float32 ZSTD-compressed, pre-pooled to chunk level, and partitioned by `doc_type` and `year` across 1976–2020), while also supporting automatic fallback to `../common/data` when running inside the `fomc-db` monorepo.

Every database build generated by `common/scripts/build_app_db.py` writes a `VERSION.json` (and `manifest.json`) containing the semantic version tag (`v1.0.0`), SHA-256 fingerprint, build timestamp, and section byte counts. The active database version is logged on startup and exposed at `GET /api/health` and `GET /api/stats` (`db_version`).

| Dataset | Standalone App Path (`fomc-app`) | `fomc-db` Generator Output | Container Mount |
| :--- | :--- | :--- | :--- |
| Text Metadata, Agendas, Speeches, Participants | `./fomc-data` | `common/data` | `/fomc-data` (`ro`) |
| Prototype Similarity Matrices (chunk-pooled `float32`) | `./fomc-data/similarities/model=bge-m3/pooling=chunk` | `common/data/similarities/model=bge-m3/pooling=chunk` | `/fomc-similarities` (`ro`) |
| Zero-Shot Macro & Subclass Labels (`doc_type=*/year=*`) | `./fomc-data/labels/zero_shot` | `common/data/labels/zero_shot` | `/fomc-labels` (`ro`) |
| Relevance Probabilities (`relevance_score.parquet`) | `./fomc-data/relevance/model` | `common/data/relevance/model` | `/fomc-relevance` (`ro`) |
| Accepted Corrections Ledger | `./fomc-data/corrections/accepted_fixes.parquet` | `./fomc-data/corrections/accepted_fixes.parquet` | `/fomc-corrections` (`rw`) |

### Updating & Versioning the Database from `fomc-db`

In the `fomc-db` repository, generate a new versioned database in `common/data` (and optionally create `common/backups/app_db-v<VERSION>.tar.zst` or copy directly to `fomc-app/fomc-data`):

```bash
# Build v1.0.0 in common/data, pack common/backups/app_db-v1.0.0.tar.zst, and sync into fomc-app/fomc-data:
python common/scripts/build_app_db.py --version 1.0.0 --notes "Initial 1976-2020 compact release" --pack --sync-app
```

When `fomc-app` lives in its own separate Git repository, simply copy the contents of `common/data/*` into `fomc-app/fomc-data/` (keeping `fomc-data/corrections/`).

On startup, the backend logs a full `[FOUND] / [MISSING]` diagnostic summary for every dataset and exposes it at `GET /api/health`.

## Key V2 Capabilities

- **Matrix Axis & Normalization Semantics:** Y-Axis = Topics, X-Axis = Chunk Sequence / Slices; normalization options are `None`, `Topic`, and `Slice` across both Explorer and Comparator.
- **Document Comparator (`/comparator`):**
  - Advanced basket filters (date/range, speaker, sex/gender, and metric threshold `>=` on any topic) + **Add All**.
  - **Combine** cohort grouping (`Year`, `Custom Year Range`, `Speaker`, `Speaker Role`, `Speaker Sex/Gender`, `Month`, `Quarter`, `Semester`) with `Mean` or `Median` aggregation.
  - Numeric **Temporal Partitions (`N`)** input and **Inspect Slice** range slider with `<` / `>` step buttons.
  - Reactive **Radar Chart**, **Time-Series Multi-Line Chart** across all slices with topic legend toggles, and **Export CSV** on the Standardized Category Scores table.
- **Access Control, Approval Workflow & Admin Console (`/admin`):**
  - Unauthenticated visitors can only access the Landing Page (`/`).
  - Root admin bootstrapped from `ADMIN_USERNAME`, `ADMIN_EMAIL`, and `ADMIN_PASSWORD` in `.env`.
  - New researcher registrations enter `PENDING` status until approved in `/admin`.
  - Admin **Fix Request Review Queue** supports Accept/Reject with optional comments, triggers automatic in-app user notifications, and appends accepted fixes atomically to `accepted_fixes.parquet`.
- **Collaborative Case Studies (`/portfolio` & `/community`):**
  - Save, edit, toggle Public/Private, or delete studies in `/portfolio`.
  - Browse public studies in `/community` with clickable **Forked from** and **Forked by** lineage links, and **Fork Study** directly from the Comparator.
- **Explorer Relevance Tab & Interactive Distribution Fix Editor (`/explorer`):**
  - Generalized `ClassificationInspector` powers both **Zero-Shot Inspector** and **Relevance Probabilities** (`Relevant` vs `Irrelevant`).
  - **Report Error / Feedback** modals on Chunks and Similarity Matrix, plus **Allow Fix Request** mode with interactive auto-normalizing probability curve sliders, **Hard Label** toggle, and synchronized dual Macro + Sub-Class editors.

## Quick Start (`DEV`)

```bash
cd mining-fomc/fomc-app
cp .env.example .env
# Edit .env to verify HOST_FOMC_DATA_DIR and set ADMIN_PASSWORD / JWT_SECRET_KEY
docker compose -f docker-compose.dev.yml up --build
```

## Production Deployment (`miningfomc.com`)

```bash
cd mining-fomc/fomc-app
cp .env.example .env
# Set strong ADMIN_PASSWORD, JWT_SECRET_KEY, POSTGRES_PASSWORD, and absolute HOST_* data paths
docker compose -f docker-compose.prod.yml up -d --build
```
